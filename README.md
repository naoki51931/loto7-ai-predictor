# LOTO7 AI Predictor

ロト7の次回数字を、**予測対象日の直近2週間に公開されていた抽選結果だけ**から予測する実験プロジェクトです。

## 予測ルール

- 予測対象の抽選結果はモデル入力に使用しない
- 予測対象日の14日前から、予測対象日の直前までの抽選結果だけを使用する
- 抽選日・曜日・抽選回番号は特徴量として使用しない
- 数字そのものから直近の出現傾向・間隔・組み合わせを特徴量化する
- バックテストでは各予測時点で利用可能だったデータだけを使う

> 注意: ロト7の抽選はランダムであり、このモデルが当選を保証するものではありません。目的は短期間の数字パターンに予測可能性があるかを検証することです。

## CSV形式

`data/loto7.csv` に以下の形式でデータを置きます。

```csv
date,n1,n2,n3,n4,n5,n6,n7
2026-01-02,1,5,9,14,22,31,37
2026-01-09,2,7,11,18,24,30,35
```

`date` はデータの期間を切り出すためだけに使い、モデルの特徴量には入りません。

## 実行

```bash
pip install -r requirements.txt
python -m src.cli --data data/loto7.csv --target-date 2026-10-23
```

バックテスト:

```bash
python -m src.cli --data data/loto7.csv --backtest 100
```
